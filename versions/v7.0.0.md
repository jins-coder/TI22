# 🚀 Titanium (Ti22) — Version 7.0.0 Release Notes
**Codename:** `Dual Engine`  
**Release Date:** 2026-09-07  
**Status:** `Stable / Production`

---

## 🌟 Overview

Titanium `v7.0.0 Dual Engine` introduces unified multi-paradigm web development to the native Rust web platform:
1. **⚡ Dual Engine Architecture:** File-based Single-File Pages (`pages/`) and Enterprise Domain-Driven MVC (`app/controllers/`, `app/models/`, `app/views/`) running simultaneously on a single unified runtime.
2. **🗃️ Embedded ActiveRecord ORM & Fluent Query Builder:** Modern chained query API (`model("products").where("stock", ">", 0).order_by("price", "DESC").get()`).
3. **🎨 Visual Web Studio DB Explorer & Interactive SQL Console:** Live database inspection, schema viewer, dynamic query runner, and route map visualization at `/__titanium_studio`.
4. **🔐 Built-in Session Authentication & Role-Based Authorization:** Secure password hashing with `crypto_hash()`, login/register/logout workflows, and protected route handlers.
5. **⚡ Zero-Flicker Turbo SPA Engine:** Debounced progress loader and intelligent soft-DOM morphing preserving active inputs, focus, selection, and scroll positions.

---

## 📦 What's New in v7.0.0

### 1. ActiveRecord ORM & Fluent Query Builder
Registered globally in the script engine:
- `model(table_name)` / `define_model(table_name, primary_key)`
- `.all()`, `.find(id)`, `.where(col, val)`, `.where(col, op, val)`
- `.order_by(col, dir)`, `.limit(n)`, `.offset(n)`
- `.create(data_map)`, `.update(id, data_map)`, `.delete(id)`, `.count()`

### 2. Dual Engine MVC View Dispatch
- `view(view_name, data_map)`: Renders templates from `app/views/` or `views/` with Minijinja/Jinja2 template inheritance and layout wrapping.

### 3. Visual Web Studio GUI (Ti22 Studio)
- `/__titanium_studio`: Web-based dashboard with:
  - Database Manager: Table schema and row browser
  - SQL Console: Live SQLite query execution
  - Route Map: Dynamic & static route discovery

### 4. Zero-Flicker Turbo SPA Client
- 120ms debounced top loader bar eliminates flashes on instant sub-100ms local responses.
- Soft-DOM tree diffing (`morphTree`) updates elements in-place without destroying active inputs or losing text selection.
