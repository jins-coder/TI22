# Carbon Major Release v4.0.0 — "Packager & Workers" (Milestone 7)

**Release Date:** September 2026  
**Status:** Milestone 7 Complete  

---

## 🌟 Overview
Carbon **v4.0.0 (Packager & Workers)** achieves **Milestone 7**, introducing CLI build validation, sliding-window rate limiting, and dedicated CLI migration & diagnostic commands.

---

## 🚀 What's New in v4.0.0

### 1. 🛡️ Sliding-Window Rate Limiter (`rate_limit`)
Built-in protection against brute-force attacks and API spam:
```rust
// In pages/_middleware.carbon or API routes
let ip = req.headers.get("x-forwarded-for");
let limit = rate_limit(ip, 100, 60); // 100 requests per 60 seconds

if !limit.allowed {
  return json(#{
    error: "Too Many Requests",
    retry_after_seconds: limit.reset_in
  }, 429);
}
```

### 2. 📦 Production Build Packaging (`carbon build`)
Validates project templates, file routing structure, and static assets for deployment:
```bash
carbon build ./my-app
```
Output:
```
  📦 Building Carbon standalone package: ./my-app
  ✅ Validated 12 page route(s)
  ✅ Bundled static assets in ./my-app/public
  ✨ Production build complete! Ready for standalone deployment.
```

### 3. 🗄️ Standalone CLI Migrations (`carbon migrate`)
Execute database migrations directly from CI/CD pipelines or scripts without starting the web server:
```bash
carbon migrate ./my-app
```

### 4. ⚡ Project Diagnostics (`carbon info`)
Prints comprehensive runtime diagnostics, directory checks, and configuration details:
```bash
carbon info ./my-app
```
