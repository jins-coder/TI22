# ⚡ Titanium (Ti22) — Version 8.0.0 Release Notes
**Codename:** `Hyperdrive Realtime`  
**Release Date:** 2026-09-07  
**Status:** `Stable / Production`

---

## 🌟 Overview

Titanium `v8.0.0 Hyperdrive` brings native ultra-low latency real-time communication, Live Channels, client-side pub/sub bridging, and real-time inspector capabilities to Titanium:

1. **📡 Native Realtime WebSocket & Live Stream Engine:** Channel-based pub/sub hub (`WebSocketHub`) embedded directly in the high-performance Rust web server with auto-fallback to HTTP SSE (`/__titanium_ws/stream`).
2. **🔄 Rhai Realtime Global APIs:** Broadcast events seamlessly from any server script or controller with `ws_broadcast(channel, data)`, `ws_broadcast_all(data)`, `ws_client_count(channel)`, `ws_channels()`, and `ws_stats()`.
3. **🌐 Client-Side Realtime Bridge & Morphing:** Built-in `window.Titanium.subscribe(channel, callback)`, `window.Titanium.broadcast(channel, data)`, and declarative `data-live="channel:key"` DOM morphing.
4. **🎨 Web Studio Realtime Inspector:** Live channel traffic monitoring, connected subscriber metrics, message inspection, and broadcast testing simulator directly in `/__titanium_studio`.
5. **🛒 Realtime E-Commerce Storefront & Admin Dispatch:** Instant real-time order alerts in the admin dashboard and live store synchronization.

## 📦 What's New in v8.0.0

### 1. Rhai Scripting Realtime Functions
- `ws_broadcast(channel, data_map)`: Broadcasts a structured event map to all active subscribers on a specific channel.
- `ws_broadcast_all(data_map)`: Broadcasts a global event to all connected clients across all channels.
- `ws_client_count(channel)`: Returns the current number of active listeners on a channel.
- `ws_channels()`: Returns a list of all active pub/sub channels.
- `ws_stats()`: Returns system-wide realtime metrics (total connected clients, total channels, message count).

### 2. Client-Side JavaScript Live Bridge
Registered automatically in `window.Titanium`:
```javascript
// Subscribe to channel events
const unsubscribe = Titanium.subscribe('orders', (data) => {
  console.log('Live order received:', data);
});

// Broadcast events from the client
Titanium.broadcast('chat', { user: 'Alice', text: 'Hello Titanium!' });
```

### 3. Server-Side Realtime Endpoints
- `GET /__titanium_ws/stream?channel=<name>`: Infinite HTTP SSE event stream with auto-reconnection and client heartbeat.
- `POST /__titanium_ws/send`: HTTP POST endpoint for client event publishing.
- `GET /__titanium_ws/history?channel=<name>`: Retrieve recent message buffer for missed events.
- `GET /__titanium_ws/stats`: JSON diagnostics of active channels and connected clients.

### 4. Web Studio GUI Realtime Inspector
- Accessible at `http://127.0.0.1:8080/__titanium_studio` -> **📡 Live WebSockets**
- Displays active channel counts, connected subscribers, live message feeds, and interactive broadcast tester.

Update your `Cargo.toml`:

Or run the CLI directly:
