# Carbon Major Release v2.0.0 — "Supernova"

**Release Date:** September 2026  
**Status:** Next-Gen Major Release  

---

## 🌟 Overview
Carbon **v2.0.0 (Supernova)** is a monumental leap forward, transforming Carbon into a powerhouse full-stack runtime. It brings server-side HTTP client capabilities, full-text fuzzy search, cryptographically secure password hashing & token generation, automatic SQL migrations, and real-time developer diagnostics.

---

## 🚀 Massive New Features in v2.0.0

### 1. ⚡ Native Server-Side HTTP Client (`http_get`, `http_post`)
Directly fetch external APIs (OpenAI, Stripe, GitHub, Shopify, Supabase) in `.carbon` scripts without external tools:
```rust
// Calling an external JSON API in a server-side script
let res = http_get("https://api.github.com/repos/rust-lang/rust", #{
  "User-Agent": "Carbon-Runtime"
});

if res.ok {
  let stargazers = res.json.stargazers_count;
  let full_name = res.json.full_name;
}

// Making a POST request with JSON payload
let payment = http_post("https://api.stripe.com/v1/charges", #{
  amount: 2000,
  currency: "usd"
}, #{
  "Authorization": "Bearer sk_test_..."
});
```

---

### 2. 🔍 Built-in Full-Text & Multi-Column Search (`db_search`)
Query across multiple columns simultaneously with ranking and limits:
```rust
// Search users by name OR email matching query term
let query = req.query.get("q");
let results = db_search("users", query, ["name", "email"]);
```

---

### 3. 🔐 Cryptographic Hashing & Security Primitives
Secure user authentication, password verification, and session token generation built into the core engine:
```rust
// 1. Hash passwords with SHA-256
let password_hash = crypto_hash(body.password);

// 2. Verify passwords on login
let is_valid = crypto_verify(body.password, user.password_hash);

// 3. Generate secure random tokens (e.g. for API keys, email verification)
let api_token = crypto_random_token(48); // e.g. "x9K3mP0q8L2v4W1s7Z6y..."
```

---

### 4. 🗄️ Automated Database Migrations (`migrations/*.sql`)
- Zero-config schema evolution. Drop raw `.sql` files into `migrations/` (`001_create_users.sql`, `002_create_orders.sql`).
- Carbon automatically executes pending migrations inside transactions on boot and tracks applied versions in `_carbon_migrations`.

---

### 5. 🛡️ Global Middleware System (`pages/_middleware.carbon`)
- Intercept and guard routes before page rendering.
- Supports short-circuiting redirects, JSON responses, and session validation:
  ```rust
  // Protect all /admin routes
  if req.path.starts_with("/admin") && session.get("role") != "admin" {
    session.flash("msg", "⛔ Admin access required!");
    return redirect("/login");
  }
  ```

---

### 6. 🎨 Custom Template Filters
- `money`: Formats cents/floats into currency (`{{ 4999 | money }}` -> `$49.99`).
- `slugify`: Converts strings to clean URL slugs (`{{ "Carbon v2.0 Release!" | slugify }}` -> `carbon-v2-0-release`).

---

### 7. 💎 Production Health Diagnostics (`/__carbon_health`)
- Health and uptime JSON metrics endpoint for cloud deployments:
  ```json
  {
    "status": "healthy",
    "version": "2.0.0",
    "engine": "Carbon (C6) Supernova",
    "sqlite": "WAL"
  }
  ```

---

### 8. 🔄 Live Reload & High-Concurrency WAL Engine
- Real-time soft-DOM live reload during development.
- SQLite tuned with `PRAGMA journal_mode = WAL` and `PRAGMA synchronous = NORMAL` for enterprise-grade concurrency.
