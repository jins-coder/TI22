# 🧠 Titanium (Ti22) — Version 9.0.0 Release Notes
**Codename:** `Singularity AI`  
**Release Date:** 2026-09-07  
**Status:** `Stable / Production`

---

## 🌟 Overview

Titanium `v9.0.0 Singularity` natively embeds intelligent AI agent runtime capabilities, real-time LLM token streaming, semantic RAG pipelines, and interactive Web Studio AI Playground directly into the high-performance Rust web engine:

1. **🧠 Built-In Singularity Neural & Multi-Provider AI Engine:** Zero-config local intelligent reasoning engine out of the box with optional OpenAI and Ollama HTTP API bridges.
2. **⚡ Ultra-Low Latency Token Streaming (SSE):** Server-Sent Events token stream endpoint `GET /__titanium_ai/stream?prompt=...` providing zero-delay client typing and real-time generation.
3. **🔍 Vector-Grounded Semantic RAG:** Native `ai_rag(query, collection, top_k)` seamlessly bridging `VectorEngine` cosine embeddings with prompt context loaders.
4. **🌐 Client-Side AI Bridge:** Frontend integration with `window.Titanium.aiStream(prompt, callbacks)`, `window.Titanium.aiChat()`, and `window.Titanium.aiRag()`.
5. **🎨 Web Studio AI Agent Playground:** Interactive prompt testing, token streaming, and RAG knowledge inspector inside `http://127.0.0.1:8080/__titanium_studio`.
6. **🛒 E-Commerce AI Store Concierge:** Live intelligent shopping advisor in `example/pages/ai_copilot.titanium`.

## 📦 What's New in v9.0.0

### 1. Rhai AI Scripting Globals
- `ai_generate(prompt)` / `ai_generate(prompt, system)`: Generates AI completions directly inside server scripts or MVC controllers.
- `ai_chat(prompt)`: Conversational assistant helper with conversational context memory.
- `ai_stream(channel, prompt)`: Streams tokens in real-time over WebSocket channels.
- `ai_rag(query, collection, top_k)`: Performs semantic vector similarity search and synthesizes a grounded answer.
- `vector_upsert(collection, id, content)`: Inserts/updates documents into the vector knowledge store.
- `vector_search(collection, query, top_k)`: Semantic vector similarity search.

### 2. Client-Side JavaScript Live AI Bridge
```javascript
// Stream AI tokens in real-time
Titanium.aiStream('Recommend a titanium watch', {
  onToken: (token, fullText) => {
    console.log('Incoming token:', token);
  },
  onDone: (fullText) => {
    console.log('Finished:', fullText);
  }
});

// Run Semantic RAG Query
const grounded = await Titanium.aiRag('Return policy on rings', 'faq', 3);
```

### 3. Server Endpoints
- `GET /__titanium_ai/stream?prompt=...&system=...`: Real-time SSE token stream.
- `POST /__titanium_ai/chat`: Interactive chat completion.
- `POST /__titanium_ai/rag`: Semantic vector retrieval and question answering.

### 4. Web Studio GUI (Ti22 Studio)
- **🧠 AI Playground & RAG Inspector:** Accessible at `http://127.0.0.1:8080/__titanium_studio`.
- Test prompts, view real-time token streaming, inspect vector cosine similarity scores, and ground agent knowledge.

## 🛠️ Upgrading to v9.0.0

Update your `Cargo.toml`:
```toml
[dependencies]
titanium = "9.0.0"
```
Or start the dev server:
```bash
titanium dev ./example
```
