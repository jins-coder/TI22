# Carbon Release v0.1.0 — "Genesis"

**Release Date:** September 2026  
**Status:** Initial Proof of Concept  

---

## 🌟 Overview
Carbon (C6) was designed as a modern native web runtime combining the rapid ergonomics of PHP, the blazing performance of Rust, and the developer simplicity of single-file components with embedded SQLite.

---

## 🚀 Key Features

### 1. Single-File Hybrid Components (`.carbon`)
- Integrated frontmatter Rhai scripting (`--- ... ---`) and MiniJinja HTML templating in one file.
- Automatic server-side evaluation before rendering.

### 2. Embedded Zero-Config SQLite
- Native SQLite database engine powered by `rusqlite`.
- Direct script functions:
  - `db_exec(sql)` — Execute DDL migrations / setup batches.
  - `db_query(sql, params)` — Query multiple records as maps.
  - `db_first(sql, params)` — Query a single record.
  - `db_run(sql, params)` — Execute parameterized mutations returning `changes` and `last_insert_id`.

### 3. File-System Dynamic Router
- Automatic route resolution based on `pages/` directory layout.
- Dynamic segment matching: `pages/users/[id].carbon` -> `/users/123`.
- API endpoints: `pages/api/*.carbon` automatically serialize return values to JSON.

### 4. Zero-Dependency Turbo SPA Engine
- Integrated client-side runtime injecting zero-reload navigation.
- Smooth top progress bar on route switches.
- Intercepted form submissions with native browser history (`pushState`) sync.

### 5. Session & Flash Messaging
- Cookie-based session storage (`carbon_session`).
- Flash messages (`session.flash("key", "val")`) that automatically clear after consumption.

---

## 🛠️ CLI Commands
- `carbon dev [dir]` — Start development server on `http://127.0.0.1:8080`.
- `carbon -S <host>:<port> -d <dir>` — Start HTTP server at custom address.
- `carbon init [dir]` — Scaffold starter Carbon project.
