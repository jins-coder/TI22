## 🌟 Overview

Titanium `v10.0.0 Supercluster (Titanium X)` marks the milestone Deca release of the Titanium web platform, introducing zero-configuration distributed clustering, multi-node mesh discovery, real-time SQLite WAL replication, and cluster topology visualization:

1. **🌐 Supercluster Mesh Network (`ClusterMesh`):** Auto-discovering peer nodes, heartbeat monitoring, and Primary-Replica cluster roles embedded in the Rust web runtime.
2. **🔄 Distributed SQLite WAL Replication:** Real-time transaction broadcasting across cluster nodes to keep distributed state consistent.
3. **📡 Cross-Node Cluster Broadcasts:** Send and synchronize events, WebSockets, and sessions across any node with `cluster_broadcast()`.
4. **🎨 Web Studio Node Topology Visualizer:** Live interactive visual cluster dashboard in `/__titanium_studio` displaying node health, roles, round-trip latency, and manual sync dispatch.
5. **⚡ Full Multi-Paradigm Integration:** Works seamlessly across Single-File Pages, MVC controllers, ActiveRecord ORM, and the Singularity AI engine.

## 📦 What's New in v10.0.0

### 1. Rhai Scripting Cluster APIs
- `cluster_node_id()`: Returns the unique identifier of the current node (e.g. `titanium-primary-node-01`).
- `cluster_is_primary()`: Returns `true` if this instance is the designated cluster leader/primary.
- `cluster_nodes()`: Returns an array of all discovered active nodes with address, role, status, and latency.
- `cluster_broadcast(event_type, payload)`: Broadcasts a cluster-wide event (such as database updates or session changes) across all mesh nodes.
- `cluster_stats()`: Returns cluster telemetry (total nodes, healthy count, primary status).

### 2. Supercluster HTTP Endpoints
- `GET /__titanium_cluster/nodes`: Discovered node topology and health status.
- `POST /__titanium_cluster/heartbeat`: Ingress endpoint for peer node heartbeats.
- `POST /__titanium_cluster/sync`: Cross-node event replication and SQLite WAL commit dispatcher.
- `GET /__titanium_cluster/stats`: Cluster summary metrics.

### 3. Web Studio GUI (Ti22 Studio)
- **🌐 Supercluster Mesh:** Dedicated interactive tab in `/__titanium_studio` with real-time topology table, primary leader status, node latency monitor, and live sync tester.

## 🛠️ Upgrading to v10.0.0

Update your `Cargo.toml`:
```toml
[dependencies]
titanium = "10.0.0"
```
Or run the CLI directly:
```bash
titanium dev ./example
```
