# Carbon Release v0.3.0 — "Shield & Stream"

**Release Date:** September 2026  
**Status:** Current Stable  

---

## 🌟 Overview
Carbon v0.3.0 introduces global route middleware (`_middleware.carbon`), native CSRF token protection, custom template filters (`money`, `slugify`), and browser cache control optimizations.

---

## 🚀 What's New in v0.3.0

### 1. 🛡️ Global & Route Middleware (`pages/_middleware.carbon`)
- Intercept incoming HTTP requests before any page execution.
- Ideal for authentication guards, role checking, maintenance mode, or logging:
  ```rust
  // pages/_middleware.carbon
  let user_role = session.get("role");
  let path = req.path;

  // Protect admin routes
  if path.starts_with("/admin") && user_role != "admin" {
    session.flash("msg", "⛔ Unauthorized access!");
    return redirect("/login");
  }
  ```
- If middleware returns `redirect(...)`, `json(...)`, or `html(...)`, the request short-circuits and immediately returns that response.

### 2. 🔒 Native CSRF Protection
- Automatic CSRF token generation via `session.csrf()` in Rhai scripts and `{{ csrf_token }}` in MiniJinja templates.
  ```html
  <form method="POST" action="/transfer">
    <input type="hidden" name="_csrf" value="{{ csrf_token }}">
    ...
  </form>
  ```

### 3. 🎨 Built-in Template Filters
- **`money`**: Converts cent integers or float values into formatted currency strings:
  ```jinja
  {{ 2499 | money }}    -> $24.99
  {{ 12.5 | money }}    -> $12.50
  ```
- **`slugify`**: Generates clean URL-safe slugs:
  ```jinja
  {{ "Hello World! Native Rust" | slugify }} -> hello-world-native-rust
  ```

### 4. ⚡ Browser Caching & Static Asset Optimizations
- Static assets in `public/` automatically include `Cache-Control: public, max-age=3600` headers for optimized client-side caching.
