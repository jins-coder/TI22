# Carbon Major Release v3.0.0 — "Pulsar" (Milestone 6)

**Release Date:** September 2026  
**Status:** Milestone 6 Complete  

---

## 🌟 Overview
Carbon **v3.0.0 (Pulsar)** fulfills **Milestone 6** by introducing real-time Server-Sent Events (SSE), AI LLM token streaming primitives, native file I/O operations, and an IDE-grade visual runtime error debugger.

---

## 🚀 What's New in v3.0.0

### 1. 🌊 Real-Time SSE & AI Token Streaming (`sse_event`, `sse_stream`)
Allows `.carbon` pages and API routes to stream events or tokens directly to the browser (e.g. for streaming ChatGPT/Claude completions, live market data, or instant status updates):
```rust
// Streaming a single SSE event
return sse_event("ai_token", #{
  token: "Carbon",
  done: false
});

// Streaming multiple event batches
return sse_stream([
  #{ event: "token", data: "Hello" },
  #{ event: "token", data: "World!" },
  #{ event: "done", data: true }
]);
```

### 2. 📁 Server-Side File I/O Primitives
Direct filesystem utilities in Rhai scripts without external dependencies:
```rust
// Check if file exists
if file_exists("public/uploads/avatar.png") {
  let content = file_read("public/uploads/data.json");
}

// Write/save content to file
file_write("public/uploads/log.txt", "Operation completed at " + session.get("time"));
```

### 3. 🎨 IDE-Grade Interactive Runtime Error Overlay
When an error occurs during development:
- Renders an in-browser debug screen.
- Shows the exact route path, error classification badge (`⚡ CARBON RUNTIME EXCEPTION`), and highlighted line numbers.
- Pre-formatted for instant copy/paste debugging.

### 4. 💎 Production Health Diagnostics
- Includes SSE streaming status in `/__carbon_health`:
  ```json
  {
    "status": "healthy",
    "version": "3.0.0",
    "engine": "Carbon (C6) Pulsar",
    "sqlite": "WAL",
    "sse": true
  }
  ```
