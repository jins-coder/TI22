## 📦 What's New in v6.0.0

### 1. In-Memory Key-Value Cache (`CacheStore`)
Thread-safe concurrent caching engine with auto-expiring TTLs and zero external Redis dependencies:
* `cache_set(key, value)` — Store value indefinitely.
* `cache_set(key, value, ttl_seconds)` — Store value with auto-expiration timestamp.
* `cache_get(key)` — Retrieve value or unit `()` if expired/missing.
* `cache_has(key)` — Fast boolean check for key presence.
* `cache_delete(key)` — Explicitly remove key.
* `cache_clear()` — Flush entire cache.
* `cache_keys()` — List active unexpired keys.
* `cache_stats()` — Inspection metrics.

### 2. In-Process Background Job Queue (`JobQueue`)
Multi-threaded async worker pool executing background tasks without blocking the HTTP request/response cycle:
* `defer_job(job_name, payload_map)` — Non-blocking worker dispatch.
* `queue_stats()` — Real-time stats (`queued`, `completed`, `recent`).

### 3. Embedded Vector & Semantic Similarity Search (`VectorEngine`)
Pure-Rust Euclidean & Cosine similarity vector mathematics for AI embeddings and documentation ranking:
* `vector_cosine_similarity(vec_a, vec_b) -> f64` — Cosine similarity score between $[-1.0, 1.0]$.
* `vector_rank(query_vec, docs_array, vector_field) -> Array` — Automatic score ranking.

### 4. Realtime PubSub Event Hub (`PubSubHub`)
Topic-based event broadcast bus for live room channels and real-time feeds:
* `pubsub_publish(topic, message)` — Broadcast event to topic channel.
* `pubsub_history(topic, [limit])` — Retrieve recent chronological events.
* `pubsub_topics()` — List active channel topics.

### 5. Pure-Rust Media & SVG Identicons (`MediaUtils`)
Deterministic visual avatars and media metadata extraction without external dependencies:
* `svg_identicon(seed, [size])` — Deterministic geometric avatar generation.
* `media_info(path)` — MIME type, size, and existence inspection.
* `media_data_uri(path)` — Base64 Data-URI generation.

### 6. Titanium Studio v6 Monitoring Endpoints
* `GET /__titanium_studio/api/cache` — Inspect active cache keys and memory stats.
* `GET /__titanium_studio/api/queue` — Monitor background job throughput.
* `GET /__titanium_studio/api/pubsub` — Inspect live topic channels.
