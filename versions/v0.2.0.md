# Carbon Release v0.2.0 — "Velocity & Ergonomics"

**Release Date:** September 2026  
**Status:** Stable Development  

---

## 🌟 Overview
Carbon v0.2.0 brings major performance tuning, live development reload, layout templates with slot rendering, ergonomic database CRUD helpers, and a built-in form validation engine.

---

## 🚀 What's New in v0.2.0

### 1. 🔄 Live Reload System (`/__carbon_live`)
- The development server continuously monitors modifications across `pages/`, `layouts/`, and `public/`.
- Embedded Turbo client listener automatically updates the page via soft-DOM morphing whenever source files change on disk.

### 2. 🧩 Layouts & Slots System
- Support for shared root layouts (`layouts/default.carbon` or `pages/_layout.carbon`).
- Pages can now omit `<!DOCTYPE html>` boilerplate and directly inject content into `<slot />` or `{{ content | safe }}`.
- Per-page layout control via frontmatter:
  ```rust
  ---
  let layout = "admin"; // Uses layouts/admin.carbon
  // or let no_layout = true;
  ---
  ```

### 3. 🗄️ SQLite Production WAL Mode & High Concurrency
- SQLite connections now automatically enable:
  ```sql
  PRAGMA journal_mode = WAL;
  PRAGMA synchronous = NORMAL;
  PRAGMA foreign_keys = ON;
  PRAGMA busy_timeout = 5000;
  ```
- **10x higher concurrent read/write throughput** under load.

### 4. 🛠️ Ergonomic Database CRUD Helpers
Eliminates repetitive SQL formatting strings in scripts:
- **`db_insert(table, map)`** — Inserts data map and returns `#{ changes: 1, last_insert_id: N }`.
  ```rust
  db_insert("users", #{ name: "Ada", email: "ada@lovelace.org", role: "systems" });
  ```
- **`db_update(table, id, map)`** — Parameterized update by ID:
  ```rust
  db_update("users", id, #{ role: "architect" });
  ```
- **`db_delete(table, id)`** — Parameterized delete by ID:
  ```rust
  db_delete("users", id);
  ```
- **`db_find(table, id)`** — Query single record map by primary key:
  ```rust
  let user = db_find("users", id);
  ```

### 5. 🛡️ Built-in Form Validation Engine
Validate inputs in one line with clear error mapping:
```rust
let res = validate(body, #{
  name: "required|min:3",
  email: "required|email",
  role: "required"
});

if !res.is_valid {
  session.flash("errors", res.errors);
  return redirect("/");
}
```

### 6. 🐛 Bug Fixes
- **Form Action Property Collision:** Fixed DOM reflection bug where `<input name="action">` shadowed `form.action` into an `HTMLInputElement` string.
- **Rhai Unit Type Checking:** Fixed missing body parameter comparison so `()` is not coerced into non-empty strings.
- **CLI Argument Flexibility:** Direct directory argument support (e.g. `carbon example`).
