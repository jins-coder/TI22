The Complete Engine & API Reference

Titanium is a high-velocity native web runtime written in Rust. Every feature — from embedded SQLite to AI agentic reasoning and distributed clustering — is built directly into the engine with zero external daemon requirements.

Installation & Development Cargo Rust 
# 1. Run local development server with Live Reload & Studio
cargo run -- dev ./example

# 2. Build optimized release binary (titanium.exe)
cargo build --release

# 3. Access Live Web Studio GUI
http://127.0.0.1:8080/__titanium_studio
Architecture Guide

1. Dual-Engine Execution Pipeline

Titanium natively supports two coexisting architectural paradigms on a single server threadpool.

Single-File Pages (pages/)

Frontmatter script blocks (--- ... ---) executed via Rhai with instant Jinja2/Minijinja SSR template evaluation. Perfect for fast, atomic, component-driven endpoints and dynamic pages.

Domain-Driven MVC (app/)

Decoupled architecture for enterprise scale:
• app/controllers/: Rhai action handlers returning view() or json().
• app/models/: ActiveRecord schemas and validation models.
• app/views/: Modular Minijinja HTML templates with inheritance.

ORM Specification

2. Fluent ActiveRecord ORM

Chainable, type-safe query builder with automatic parameterized SQLite binding.

model(table: String) -> QueryBuilder ActiveRecord Root

Initializes a fluent query builder for the given database table.

let builder = model("products");
.where(column, value) / .where(column, operator, value) Filtering

Appends SQL WHERE conditions with automatic parameter escaping.

let items = model("products")
  .where("category", "Watches")
  .where("price", ">=", 150.0)
  .where("stock", ">", 0)
  .get();
.order_by(col, dir).limit(n).offset(n) Pagination & Sorting 
let paged = model("orders")
  .order_by("created_at", "DESC")
  .limit(20)
  .offset(40)
  .get();
.create(map) / .update(id, map) / .delete(id) / .find(id) Mutation & Retrieval 
// Create new product
let item = model("products").create(#{
  name: "Titanium Pen",
  price: 79.0,
  stock: 50
});

// Find by primary key
let watch = model("products").find(4);

// Update by primary key
model("products").update(4, #{ stock: 45 });

// Delete by primary key
model("cart_items").delete(12);
Database API

3. Embedded SQLite & Raw SQL

High-concurrency SQLite operations in WAL (Write-Ahead Logging) mode.

Function Arguments Returns Description
db_query sql, params? Array Executes a SELECT query and returns an array of maps.
db_first sql, params? Dynamic (Map/()) Returns the first matching row or () if not found.
db_run sql, params Map Executes INSERT/UPDATE/DELETE and returns #{ rows_affected, last_insert_id }.
db_exec sql () Executes raw DDL schema statements (CREATE TABLE, ALTER TABLE, etc.).
db_insert table, data_map Map Convenience helper to insert a map into a table.
db_update table, id, data_map Map Convenience helper to update columns by row id.
db_delete table, id Map Deletes a row by primary key.
db_search table, query, columns Array Fuzzy LIKE search across specified columns.
Realtime API

4. Hyperdrive WebSockets & Live Channels

Zero-config multi-channel pub/sub routing with automatic SSE fallback.

ws_broadcast(channel: String, data: Dynamic) -> Dynamic Rhai Server

Broadcasts a message map to all active subscribers of a named channel.

ws_broadcast("orders", #{
  order_id: 1042,
  customer: "Bob",
  total: 349.00
});
ws_client_count(channel) / ws_channels() / ws_stats() Telemetry 
let active_listeners = ws_client_count("inventory");
let topics = ws_channels();
let realtime_metrics = ws_stats();
window.Titanium.subscribe(channel, callback) Frontend Client 
// Subscribe to channel in browser
const unsubscribe = window.Titanium.subscribe('orders', (order) => {
  console.log('⚡ Received order:', order);
});

// Broadcast event from browser
window.Titanium.broadcast('chat', { user: 'Alice', text: 'Hello!' });
AI Engine

5. Singularity AI & Vector Semantic RAG

Native AI reasoner, real-time token streaming, and semantic vector cosine embeddings.

ai_generate(prompt, system?) / ai_chat(prompt) Generation 
let answer = ai_generate("Summarize stock status", "You are an inventory assistant.");
ai_rag(query, collection, top_k) Semantic RAG 
// 1. Ingest into Vector Store
vector_upsert("catalog", "prod_1", "Stealth Watch: Grade 5 titanium, 200M water resistance, $349.99");

// 2. Synthesize Grounded Answer via Vector Cosine Similarity
let result = ai_rag("What is the price of the watch?", "catalog", 3);
// Returns: #{ query, answer, sources, sources_count }
Titanium.aiStream(prompt, callbacks) Client Streaming 
Titanium.aiStream("Recommend an EDC knife", {
  onToken: (token, fullText) => {
    document.getElementById('ai-output').innerText = fullText;
  },
  onDone: (fullText) => console.log('Complete response:', fullText),
  onError: (err) => console.error(err)
});
Distributed Clustering

6. Supercluster X Mesh & Replication

Zero-config peer node discovery, Primary-Replica cluster leadership, and distributed SQLite WAL sync.

// Node Identity & Role
let node = cluster_node_id();      // e.g. "titanium-primary-node-01"
let is_leader = cluster_is_primary(); // true / false

// Retrieve Mesh Topology & Ping Latencies
let mesh = cluster_nodes();
// [#{ id: "node-1", address: "127.0.0.1:8080", role: "primary", status: "healthy", latency_ms: 1 }]

// Cross-Node Sync & WAL Commit Broadcast
cluster_broadcast("wal_sync", #{
  table: "orders",
  action: "insert",
  record_id: 1042
});

// Cluster Summary Telemetry
let stats = cluster_stats();
HTTP & Security

7. HTTP Responses, Sessions & Crypto

Request context, session state management, redirects, and cryptographic hashing.

Method Example Description
redirect redirect("/login") Issues a 302 (or custom) redirect response.
json json(#{ status: "ok" }) Returns application/json with serialized map/array.
view view("admin/index", #{ ... }) Renders template from app/views/ with data map.
session.get / set session.set("user_id", 42) Encrypted cookie session key-value storage.
session.flash session.flash("msg", "Saved!") One-time flash message cleared after next read.
crypto_hash crypto_hash("secret123") SHA-256 cryptographic password hashing.
crypto_verify crypto_verify(plain, hash) Validates password against hash.
rate_limit rate_limit(key, 60, 60) Sliding-window IP/user request throttler.
