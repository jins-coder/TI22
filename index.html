MVC Controller (app/controllers/products.rhai) Clean Domain 
// Product Catalog Controller
fn index(req, session) {
  let products = model("products")
    .where("stock", ">", 0)
    .order_by("price", "DESC")
    .limit(10)
    .get();

  return view("products/index", #{
    title: "Catalog",
    items: products
  });
}

  .get();

Live Streams

3. Hyperdrive WebSockets & Live Channels

Server-Side Broadcast (Rhai)

// Broadcast order event to live subscribers
ws_broadcast("orders", #{
  order_number: "TI-10042",
  customer: "Alice",
  total: 189.00
});

// Broadcast across all connected clients
ws_broadcast_all(#{ announcement: "Flash sale active!" });

Client-Side JavaScript Bridge

// Subscribe to channel in browser
const unsub = Titanium.subscribe('orders', (order) => {
  showToast(`New Order #${order.order_number}: $${order.total}`);
});

// Broadcast from browser
Titanium.broadcast('chat', { text: 'Hello!' });

Agentic Intelligence

4. Singularity AI & Semantic Vector RAG

// 1. Vector Knowledge Upsert
vector_upsert("faq", "doc_1", "Our return window is 30 days for Grade 5 titanium products.");

// 2. Semantic RAG Query
let answer = ai_rag("What is the return policy?", "faq", 3);

// 3. Client Real-Time Token Streaming
Titanium.aiStream("Recommend an EDC knife", {
  onToken: (token, fullText) => updateUI(fullText),
  onDone: (fullText) => finishUI()
});

Quick Cheatsheet

Global Rhai & JavaScript API Reference

Category Function Signature Description
ORM & DB model(table) ActiveRecord query builder (.where, .order_by, .limit, .get, .find, .create)
Realtime ws_broadcast(channel, data) Broadcast message to live channel subscribers
Singularity AI ai_generate(prompt) / ai_rag(query) Generate AI response or run vector-grounded semantic retrieval
Cluster cluster_broadcast(event, payload) Broadcast event across multi-node Supercluster mesh
Frontend JS Titanium.subscribe(channel, cb) Live WebSocket subscriber with data-live soft-morphing
Frontend JS Titanium.aiStream(prompt, options) Live token-by-token SSE streaming receiver
