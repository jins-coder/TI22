Prologue

Architecture & Philosophy

Understanding the fundamental advantages of the Titanium native web platform.

Traditional modern web development requires assembling dozens of fragile, heavy layers: Node.js or Python runtime engines, external Redis servers, PostgreSQL/MySQL clusters, NGINX reverse proxies, WebSocket daemons, task queue runners, and gigabytes of node_modules.

Titanium (Ti22) rewrites this paradigm. Written entirely in high-performance bare-metal Rust, Titanium embeds the entire web stack into a single zero-dependency compiled binary:

⚡ Zero Runtime Dependencies

Compiles directly to native machine code. No Node.js, V8, Python, or Ruby interpreter needed.

🗄️ Embedded Concurrency

SQLite in WAL mode executes queries in sub-millisecond memory-mapped pages with zero network hops.

🌐 All-In-One Battery Included

Built-in WebSockets, In-Memory TTL Cache, Background Queues, AI Agents, and Multi-Node Cluster.

Why the name Titanium (Ti22)?

Named after Element 22 on the periodic table — renowned for its extraordinary strength-to-weight ratio, high corrosion resistance, and aerospace durability. Titanium embodies these exact attributes in software engineering.

Installation & Setup

Titanium can be executed directly via Cargo or deployed as a standalone native binary:

# 1. Clone the repository
git clone https://github.com/jins-coder/TI22.git
cd TI22

# 2. Launch live development server with Hot Module Reloading & Web Studio
cargo run -- dev ./example

# 3. Access web application & GUI
http://127.0.0.1:8080
http://127.0.0.1:8080/__titanium_studio

Configuration (titanium.toml)

Titanium is configured via an optional titanium.toml file in your project root:

[server]
host = "127.0.0.1"
port = 8080
workers = 4

[database]
path = ".titanium/app.sqlite"
wal_mode = true

[cache]
default_ttl = 300

[queue]
worker_threads = 2

[cluster]
node_id = "node-alpha-01"
is_primary = true
Architecture

Dual-Engine Execution Pipeline

Choose between rapid single-file agility or disciplined enterprise domain structures.

1. Single-File Pages (pages/)

Component Driven

Frontmatter script header parsed with Rhai followed by Jinja2 SSR body:

---
let product = model("products").find(params.id);
if product == () { return redirect("/404"); }
---
<h1>{{ product.name }}</h1>
<p>${{ product.price }}</p>

2. Domain-Driven MVC (app/)

Enterprise Clean

Decoupled MVC controllers in app/controllers/:

// app/controllers/catalog.rhai
fn show(req, session) {
  let item = model("products").find(req.params.id);
  return view("catalog/show", #{ product: item });
}

Database & ORM

ActiveRecord Fluent Query Builder

The primary database querying interface in Titanium (The Eloquent of Titanium).

Retrieving Records

// 1. Retrieve all records
let all_products = model("products").all();

// 2. Find by primary key (id)
let watch = model("products").find(4);

// 3. Complex chained filters
let results = model("products")
  .where("category", "Watches")
  .where("price", ">=", 150.0)
  .where("stock", ">", 0)
  .order_by("price", "DESC")
  .limit(10)
  .offset(0)
  .get();

// 4. Retrieve single first matching record
let user = model("users").where("email", "alice@titanium.dev").first();

// 5. Count matching records
let total_active = model("orders").where("status", "Processing").count();

Creating & Mutating Records

// Create new record
let new_order = model("orders").create(#{
  order_number: "TI-10084",
  customer_name: "Alice Smith",
  total: 349.99,
  status: "Processing"
});

// Update record by primary key
model("products").update(4, #{ price: 299.99, stock: 18 });

// Delete record by primary key
model("cart_items").delete(15);
SQLite Engine

Embedded SQLite & Raw SQL

Function Arguments Returns Description
db_query sql, params? Array Executes a SELECT query and returns an array of maps.
db_first sql, params? Dynamic Returns the first matching row or () if not found.
db_run sql, params Map Executes mutation returning rows_affected & last_insert_id.
db_exec sql () Executes raw DDL schema statements (CREATE TABLE, etc.).
Realtime

Hyperdrive WebSockets & Live Channels

Server-Side Broadcasting (Rhai)

// Broadcast to a specific channel topic
ws_broadcast("orders", #{
  order_id: 104,
  order_number: "TI-8491",
  total: 189.0,
  customer_name: "John Doe"
});

// Broadcast globally to all connected clients
ws_broadcast_all(#{ announcement: "Flash sale active!" });

Client-Side JavaScript Bridge (window.Titanium)

// Subscribe to channel events in browser
const unsubscribe = window.Titanium.subscribe('orders', (payload, message) => {
  console.log('⚡ Received live order payload:', payload);
});

// Broadcast event from browser
window.Titanium.broadcast('chat', { user: 'Alice', text: 'Hello!' });
Singularity AI

Singularity AI & Vector Semantic RAG

Vector Ingestion & Semantic RAG Grounding

// 1. Ingest document into vector collection
vector_upsert("faq", "return_rule", "All unworn titanium gear can be returned within 30 days for a full refund.");

// 2. Perform Semantic RAG (Retrieval Augmented Generation)
let rag_result = ai_rag("Can I return my watch after 2 weeks?", "faq", 3);

Live Token-By-Token Streaming (Frontend SSE)

window.Titanium.aiStream("Recommend top 3 titanium EDC pens", {
  onToken: (token, fullText) => {
    document.getElementById('ai-bubble').innerText = fullText;
  },
  onDone: (fullText) => console.log('Stream completed:', fullText)
});
